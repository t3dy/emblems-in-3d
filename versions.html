Versions

The world keeps changing. A version that exists only in git history is a version nobody can visit, so each one is frozen at its own URL and stays there.

The current world Phase 5 Versions

What is frozen and what is shared. Each archived version keeps its own copy of the page, the stylesheet, the renderer and all of its content — so the numbers, the text and the geometry it shipped with are exactly what you get. What it does not copy is the image assets: the 1617 plates and the 1499 leaves are scans of paper, they are facts rather than code, and they do not change when the world does. Any future version that needs to change an asset rather than add one has to copy it and say so in its manifest.

Archived by tools/archive_version.py; the index is site/data/versions.json.
