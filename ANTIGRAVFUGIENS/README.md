# ANTIGRAVFUGIENS

`ANTIGRAVFUGIENS` is a separate experiment branch for the Atalanta material. It keeps the fifty emblem fugues as the core, but treats them as surreal game soundtracks rather than as faithful playback objects.

Each emblem has ten versions. The versions still use the ten NES game palettes from the parent project, but each one also adds a different studio/game trick: tape delay, mercury vibrato, gated black-fire envelopes, albedo wash, arpeggiated citrinitas harmony, rubedo phasing, ouroboric feedback, square-wave bass, volatile ladder tones, and projection glitch.

The visual experiments are deliberately weirder than the main gallery:

- Levitating Athanor: fugue pressure makes the plate hover; clicking vents heat.
- Ouroboric Dub: feedback draws a self-feeding circular serpent.
- Dewpoint Runner: vibrato and delay turn the emblem into a moisture field.
- Sword/Egg Breakbeat: short envelopes and downbeat hits cut the egg.
- Rose-Garden Lockstep: harmonies rotate geometric locks.
- Sublimation Pinball: notes become charged pellets in a volatile cabinet.
